# Kupa–Akpu Code Review Repository

## 👋 Overview
This repository is created by **Kupa** for the purpose of getting code reviewed by **Akpu**.

The goal is to:
- Improve code quality
- Learn best practices
- Get constructive feedback
- Track learning progress over time

---

## 🧑‍💻 Roles
- **Author:** Kupa
- **Reviewer:** Akpu

---

## 📂 Repository Structure
- Each folder represents a small project, task, or concept
- Code will be pushed by Kupa
- Reviews and suggestions will be provided by Akpu via comments or PR reviews

---

## 🔁 Review Workflow
1. Kupa pushes code to a feature branch
2. A Pull Request (PR) is created
3. Akpu reviews the code and leaves feedback
4. Kupa updates the code based on suggestions
5. PR is merged after approval

---

## ✅ Review Guidelines
- Focus on readability and clarity
- Suggest better practices where applicable
- Explain *why* a change is recommended
- Be honest, respectful, and constructive

---

## 🎯 Goal
To continuously improve coding skills through consistent review and collaboration.

---

## 📌 Notes
This repository is for learning purposes and may contain experimental or incomplete code.

Happy reviewing 🚀
